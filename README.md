# БЕЛВЭБ — прототип открытия счёта на основе TechUI

Отдельный интерактивный прототип: ИП/юридическое лицо, условные поля, клиентская проверка формата, сводка, возврат и сброс. Не отправляет формы в банк. Секреты исходного сайта не используются и не включены в проект.

## Запуск

```sh
npm run dev -- --host 127.0.0.1
```

## Проверки

```sh
npx tsc --noEmit
npm run build
```

Основной интерфейс — `app/page.tsx`, оформление и токены — `app/globals.css`. Логотипы взяты с исходного сайта, Manrope — из TechUI Storybook. Результаты аудита, границы проверки и отличия от полноценной интеграции описаны в [UX-AUDIT.md](UX-AUDIT.md).

Данные формы хранятся только в состоянии React текущей вкладки; обновление страницы очищает их.

## Итерация по Figma

Убраны шапка, футер, боковая колонка, шаги и пояснения о прототипе. Форма в одну колонку шириной 450 px, вертикальный выбор типа заявителя, одна основная кнопка. Композиция сверена с Final Design (`2102:24105`) и NEW OCT (`3298:29862`, `3298:29893`) в файле `jU2v2STdjmdazW8OHhHrA6`. Шрифт, цвета и поля сохранены из TechUI. Логотип и иконки загружены из Figma в `public/assets/figma-*.svg`.

## Полная анкета

После «Открыть счет» открывается «Заявление на комплексное обслуживание». Для ИП и юридического лица перенесены исходные вопросы, ОКЭД, валютные счета, пакеты услуг, зарплатный проект, выбор офиса, документы и согласия. Данные и утверждённые тексты сохранены в `app/source-content.json` и `app/source-copy.json` без редакторских изменений. Компоненты сверены с Solar 1.0 (`XvjAEoJqExd4XwTu5Nby0P`, Inputs Outline `2775:45254`).

Введённые данные и выбранные файлы остаются в памяти вкладки. МСИ, камера, биометрия, государственные реестры и отправка заявки в банк не вызываются. После проверки формы открывается локальная сводка с возможностью вернуться к редактированию.
